## 简介
这个是微信与claude code之间的桥接服务，起因是微信开放了openclaw的接口。大家可以在微信-设置-插件里面找到这个插件。插件是让你在openclaw服务器上安装一个插件，然后通过这个插件扫码进行验证，然后在微信上的聊天页能找到这个插件，默认是微信crewbot（我记得是这个），你可以跟他聊天。

因为我们常用的是claude code，所以我们使用桥接器的方案，让他伪装成openclaw跟相关插件交互

## 操作首发
1. 拉取代码
2. npm install 安装以来
3. npm run login 微信扫码认证
4. npm start 启动桥接器


## 使用
1. 直接对话，claude api进行回复
2. /cli 代码问题，可支持代码保存在本地
